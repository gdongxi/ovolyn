# OVOLYN — 标志文件 (1c 铸边金库 / Reeded Vault)

所有文件为矢量 SVG，viewBox 坐标系统一 120×120（符号）。黑 = #201f1d，反白 = #f3f2f2。

| 文件 | 用途 |
|---|---|
| ovolyn-mark.svg | 主符号，浅底。最小 32px |
| ovolyn-mark-reversed.svg | 主符号，深底 |
| ovolyn-lockup-vertical.svg | 纵向锁定（deck 封面、海报） |
| ovolyn-lockup-vertical-reversed.svg | 纵向锁定，深底 |
| ovolyn-lockup-horizontal.svg | 横向锁定（导航栏、README） |
| ovolyn-lockup-horizontal-reversed.svg | 横向锁定，深底 |
| ovolyn-lockup-tagline.svg | 带 tagline，用于首屏与物料 |
| ovolyn-icon.svg | 简化符号，24–32px |
| ovolyn-icon-reversed.svg | 简化符号，深底 |
| ovolyn-favicon.svg | 16px 专用，最粗一版 |
| ovolyn-avatar.svg | 圆形头像，黑底反白 |

## 注意

- 字标使用 Cormorant Garamond Regular（Google Fonts / OFL）。锁定类 SVG 内的字标是 **活字**，未转曲：网页内联使用正常；交付给印刷厂或第三方前请在 Figma / Illustrator 里「转换为轮廓」，或让我出转曲版本。
- 符号（mark / icon / favicon / avatar）不含文字，任何环境都可直接用。
- 滚花边是 60 根等距描边线，不是纹理。不要用位图替代，也不要单独改描边粗细——整体等比缩放。
